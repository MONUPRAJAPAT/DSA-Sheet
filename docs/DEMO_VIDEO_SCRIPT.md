# Demo video script (target: 4 min 30 s)

The PDF asks the video to cover **application flow**, **key features** and **progress tracking**. Record at 1080p in a clean browser profile, with the zoom at 110 % and notifications off. Have two tabs ready: the live AWS URL and the `docs/SYSTEM_DESIGN.md` architecture diagram.

| Time          | Screen                                         | What to say                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **0:00–0:20** | Landing page                                   | "This is DSA Sheet, a MERN + TypeScript app deployed on AWS that helps students plan, track and revise their DSA preparation. It has 12 chapters, 39 topics and 200 hand-picked problems, and every link is verified automatically."                                                                                                                                                                                                                                                                                                                                                                                                              |
| **0:20–0:45** | Click **Get started** → register a new account | "Login is secure. Passwords are bcrypt-hashed, and the session uses a 15-minute access token kept only in memory plus a rotating httpOnly refresh cookie, so nothing sensitive sits in localStorage." Show the instant validation message for a weak password.                                                                                                                                                                                                                                                                                                                                                                                    |
| **0:45–1:30** | **DSA Sheet**: chapter grid → open **Arrays**  | "This is the hierarchy from the brief: chapter, then topics, then problems. Each topic has its own difficulty tag and three learning resources." Hover the **Learn** links. "Each problem has a YouTube explanation, a LeetCode or Codeforces practice link and an article, plus an Easy, Medium or Hard tag." Use the difficulty and status filters, press **⌘K**, and search "binary search".                                                                                                                                                                                                                                                   |
| **1:30–2:30** | **Progress tracking** (the key part)           | Tick 2 problems on a fresh account. "The checkbox updates instantly with an optimistic update, and the change is persisted with an idempotent upsert. The first solve gets a small celebration, and every solve can be undone from the toast." Point at the topic bar, the chapter ring and the sidebar progress. Star one problem and add a note. **Log out**, log back in, and show the **Continue where you left off** card on the dashboard. Click **Resume**: it deep-links to and highlights the next problem. Reload the page to show the session restoring from the cookie. "That's the 'resume exactly where you left off' requirement." |
| **2:30–3:30** | **Study Calendar**                             | "The calendar is a full page with three jobs: plan, track and revisit." Open **Generate study plan**, set a target date and show the live capacity warning with its "use 4 per day" suggestion, then generate. Drag a backlog problem onto a day, and drag a task to another day. Open a task and **Mark done**: "completing a study task also ticks the problem on the sheet." Show the **revision** events created by the earlier ticks: "spaced repetition at 1, 3, 7 and 21 days." Show the overdue banner and **Move to today**, then the Week and Agenda views and **Export .ics**.                                                         |
| **3:30–3:50** | **Dashboard** + **Revision** + dark mode       | Streak, heatmap, difficulty split, chapter progress and today's agenda, then the revision queue. Toggle dark mode and shrink the window to mobile width.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **3:50–4:30** | `SYSTEM_DESIGN.md` diagram + terminal          | "Architecture: CloudFront serves the React build from S3 and routes `/api` to an autoscaling ECS Fargate service behind a load balancer, backed by MongoDB Atlas, all in Mumbai. The API is stateless, every per-user query is indexed, and the shared sheet is cached at the edge. Under load testing, 500 concurrent students gave a p95 of 28 ms with zero errors, and one instance sustains about 600 requests per second." Briefly show `npm test` passing (26 tests), the Playwright E2E run, and `/api/docs` (Swagger). "Everything deploys with one command, or through GitHub Actions on merge."                                         |
| **4:30**      | Back to the app                                | "Thanks for watching."                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

**Tips**

- Use the **demo account** for the calendar section: it already has history (34 solved, a 16-day streak, revisions and a plan), so the calendar looks realistic.
- Re-seed it just before recording (`./infra/aws/deploy.sh seed`) so the numbers match this script.
